### 1.1 原始TITA RL不是只有普通PPO

| 内容 | 静态证据位置（相对上游本地根目录） | 对选题的影响 |
|---|---|---|
| 方法来源 | `README.md:14` 链接 [LocomotionWithNP3O](https://github.com/zeonsunlightyu/LocomotionWithNP3O) | 应追踪算法与表征的不同来源，不能只引用TITA仓库 |
| 约束RL | `configs/tita_constraint_config.py`、`algorithm/np3o.py`、`runner/on_constraint_policy_runner.py` | 已有reward、cost critic、cost advantage和违反代价更新；“加约束RL”不是空白 |
| 六项cost | 配置的`costs`与`envs/legged_robot.py:1358`起 | 位置、力矩、速度、加速度、接触力、绊碰等已纳入设计；仍需审计实际约束是否有效 |
| 本体状态与历史 | `envs/legged_robot.py:335`、`modules/actor_critic.py:764` | 已有33维本体观测和10帧历史；“加入历史”不是独立新贡献 |
| 表征学习 | `MlpBarlowTwinsActor`和`imitation_learning_loss()` | 已有Barlow Twins类辅助目标与部分特权量监督；“加自监督”需明确实质差异 |
| 非对称训练 | `evaluate()`与`evaluate_cost()` | critic使用高度、动力学特权量和历史编码；动作策略的输入更受限 |
| 随机化与执行 | 配置`domain_rand`、动作滤波/延迟、PD及轮力矩映射 | 质量/质心、摩擦、电机、PD增益和时延等并非尚待首次加入 |
| 部署 | README与 [sim2sim2real仓库](https://github.com/DDTRobot/tita_rl_sim2sim2real) | 已有Webots与板端推理路线；单纯导出部署通常属于基础工程 |

本地默认完整观测可整理为：33维本体＋187维高度＋36维特权量＋330维历史，共586维。当前Lab将36维特权量拆成6维状态与30维动力学组。**这不是部署actor必须读取586维的意思。**

`ActorCriticBarlowTwins.act_teacher()`实际只从大观测向量中切出当前本体与历史，再调用动作网络；方法名带teacher不意味着它直接读取地形真值。高度与其他特权量进入价值/代价网络。任务配置`depth.use_camera=False`。因此，该默认方案不能直接被描述成深度视觉运动控制。

另一个实验设计细节：上游任务配置默认`resume=True`，指向示例checkpoint。比较学习效率时，必须明确是否从头训练、是否使用预训练权重，以及各方法的初始化和训练预算。

以上源于本地文件读取。公开入口：[DDTRobot/tita_rl](https://github.com/DDTRobot/tita_rl)。未核对本地副本与远端当前commit的一致性，不宣称逐行审计了所有上游分支。

## 2. TITA RL背后的论文并不是唯一一篇

能确认的来源链为：

1. TITA README明确引用`LocomotionWithNP3O`。
2. 该上游仓库 [dev分支README](https://github.com/zeonsunlightyu/LocomotionWithNP3O/blob/dev/README.md) 说明作者使用HIM类似的单阶段训练思路、采用Barlow Twins，并表示当时没有发论文的时间。该说明只能代表该版本与时间，不能证明此后永远没有论文。
3. 约束算法最相关的原始研究是P02；HIM思路对应P03；Barlow Twins目标对应P04。具体实现存在修改，不能把TITA说成其中任何一篇的完整官方复现。

应分别引用“平台/实现”“约束优化方法”“表征学习方法”。本轮没有找到一篇能被确认是整个`DDTRobot/tita_rl`唯一正式配套论文的文献。

## 3. 直接相关文献：已有工作做到哪里

### P01. 用户指定的八自由度平衡—运动控制论文｜A

Wang、Ma、Chen，RICAI 2025：[A Balance-Motion Control Framework for an Eight-Degree-of-Freedom Wheeled Bipedal Robot](https://ieeexplore.ieee.org/document/11385317)。在线访问受限后，在用户Zotero找到PDF，已读六页正文并核对图表。明确采用本末科技TITA；单刚体MPC处理机身平衡，WLIP与按腿长拟合增益的离线LQR处理轮运动；包含Webots与真实TITA测试。它直接证明现成TITA可以承载控制研究，但其实验范围不能等同于任意复杂地形。详细笔记见04。

### P02. 约束RL与N-P3O｜A

Lee等，2023：[Evaluation of Constrained Reinforcement Learning Algorithms for Legged Locomotion](https://arxiv.org/html/2309.15430)。核对了CMDP、cost advantage归一化、算法比较及实机验证段落。它将物理约束与任务奖励分开，并比较多种一阶方法。启发：你的安全研究需要超出“增加一列cost”；平均累计约束也不能自动变成逐时刻安全保证。

### P03. HIM内部表征｜A

Long等，2023/2024：[Hybrid Internal Model: Learning Agile Legged Locomotion with Simulated Robot Response](https://arxiv.org/html/2312.11460)。核对了部分观测、辅助表征优化、与PPO的训练关系及仿真/真实比较。启发：历史编码与隐式环境推断已有强基线；需要解释你的表示捕获什么信息、何时更可靠、如何影响控制。

### P04. Barlow Twins｜B

Zbontar等，ICML 2021：[Barlow Twins: Self-Supervised Learning via Redundancy Reduction](https://proceedings.mlr.press/v139/zbontar21a.html)。核对原始摘要。以交叉相关矩阵接近单位阵来学习表示并减少维度冗余。它是通用表征目标；换到TITA上不自动构成新的机器人学习方法。

### P05. RMA｜B

Kumar等，RSS 2021：[RMA: Rapid Motor Adaptation for Legged Robots](https://www.roboticsproceedings.org/rss17/p011.html)。核对原始摘要与训练/部署图说明。基策略与历史适应模块组合，仿真训练后在A1上部署。启发：未知动力学适应至少要和这种显式适应思路比较，不能仅比较无历史PPO。

### P06. DreamWaQ｜B

Nahrendra等，2023：[DreamWaQ](https://arxiv.org/abs/2301.10602)。原始摘要报告有限传感条件下的复杂地形运动及真实室外验证。作为隐式地形/状态表征的相邻基线；本轮未审计其完整训练实现。

### P07. 鲁棒感知运动控制｜B

Miki等，2022：[Learning robust perceptive locomotion for quadrupedal robots in the wild](https://arxiv.org/abs/2201.08117)。核对原始摘要中的本体/外部感知融合与感知退化问题。启发：加深度图本身不足以创新，遮挡、错误高度、噪声下的融合与行为变化更值得研究。

### P08. 双足/轮足盲爬楼梯｜A

Chamorro等，2024：[Reinforcement Learning for Blind Stair Climbing with Legged and Wheeled-Legged Robots](https://arxiv.org/html/2402.06143)。核对位置目标任务、非对称训练、模式观测及实验。仿真涉及不同形态，Ascento有真实台阶验证。启发：“使双轮足上台阶”已非空白；任务定义、轮径和轮胎差异必须纳入比较。

### P09. CTBC｜A

Li等，2025，当前页面为2026年v3：[CTBC](https://arxiv.org/html/2509.02986)。核对接触触发、前馈指导及退火、域随机化和实验设置。报告Tron1等平台的连续爬阶。启发：靠接触触发抬腿、课程/指导减小探索难度已有直接先例；不能只换TITA名称。

### P10. 视觉摩擦先验＋RL｜A

Peng等，2024预印本、2025修订：[Friction-Aware Safety Locomotion for Wheeled-legged Robots using Vision Language Models and Reinforcement Learning](https://arxiv.org/html/2409.09845)。核对摩擦估计、WIP实验和局限性。作者报告摩擦高估会影响成功率，估计速度也有限。启发：可研究错误先验、不确定性与本体证据融合；“视觉预测摩擦再喂RL”已有直接工作。图像无法单独确定所有轮胎—地面接触条件，应验证这种假设。

### P11. 对抗扰动与H∞｜B

Long等，2024：[Learning H-Infinity Locomotion Control](https://arxiv.org/abs/2404.14405)。核对原始摘要和公开算法/局限片段。将状态相关扰动与控制学习结合，并约束任务代价与扰动强度关系。启发：随机推扰升级为对抗推扰已有方法基础，不能仅改扰动采样就宣布首创。

### P12. 运动能力感知导航｜A

Lee等，Science Robotics 2024：[Learning Robust Autonomous Navigation and Locomotion for Wheeled-Legged Robots](https://arxiv.org/html/2405.01792)。核对分层导航/运动、传统导航比较和失败案例。工作展示几何规划与真实跟踪能力、遮挡和延迟的关系。启发：平衡可行性导航有合理问题来源，但不能把“高低层结合”本身当成新贡献。

### P13. TITA视觉语义导航：ZONDA｜A

Liang等，2026预印本：[ZONDA](https://arxiv.org/html/2607.21025)。核对多楼层规划、多视角核验、动态行人避让、消融与实机段落。**真实TITA演示是单楼层办公室，重模型在外部工作站运行，采用ROS2和MPPI执行局部运动。** 多楼层benchmark结果不能直接改写成TITA实机跨楼层能力。启发：TITA确能承载高层具身导航；该文不证明TITA已成为通用VLA平台。

### P14. 无臂轮足跌倒恢复：FTSR｜A

Hou等，2026：[Robust Fall Recovery for Armless Bipedal-Wheeled Robots via Force-Guided Learning](https://arxiv.org/html/2606.14270)。核对辅助力约束、分阶段奖励、消融与真实实验。实机为作者自研JiaRan，不是TITA。启发：无臂轮足随机姿态恢复已有人研究，接触建模和本体可恢复性会成为主要难点；不宜把“站起来”当作低风险空白课题。

### P15. 轮端操作物体｜A

Qin等，2026预印本：[Mobile Pedipulation for Object Sliding via Hierarchical Control on a Wheeled Bipedal Robot](https://arxiv.org/html/2606.19233)。核对TRB/TRBO模型、接触模式与摩擦约束、规划/控制及实验相关段落。采用轮腿完成物体滑动，具有真实实验。启发：TITA无机械臂也可能研究交互任务，但需要同时处理平衡、接触和物体状态，风险高于基础运动控制。不能默认他人模型参数与TITA兼容。

### P16. 视觉内部模型＋规划：VIP-Loco｜A

Shirwatkar等，2026预印本：[VIP-Loco](https://arxiv.org/html/2603.14345)。核对内部模型训练、约束规划及实验。报告Go1、Cassie、轮足TronA1-W等形态的仿真结果；各形态分别训练。启发：纯仿真也可组织有机制、消融和多形态的研究，但预印本不是同济学位合格证明；“世界模型＋MPC＋RL”组合也已有先例。

### P17. 多形态扩散运动：Multi-Loco｜A

Yang等，2025预印本：[Multi-Loco](https://arxiv.org/html/2506.11470)。核对维度处理、共享扩散先验、残差策略、多critic与评价设置。涉及轮足等多种形态及真实部署。启发：若做跨机器人策略或扩散控制，数据生成、形态对齐和推理成本都需实质贡献；“换扩散模型”不是充分理由。

## 5. 本轮文献共同划出的边界

- 基础平衡、速度跟踪、盲爬阶、历史适应、约束RL、视觉地形输入和分层导航，都已有充分先例。它们可以是研究组成部分，不能只按功能命名创新。
- “新平台上验证已有方法”有工程价值；作为学硕主要贡献时，需要说明新增问题及一般化认识，不能只说原作者没用过TITA。
- 直接竞争者与相邻方法的作用不同：CTBC与盲爬阶属于很近的功能对照，HIM/RMA是表征适应基线，P12/P13是导航参照，P18是模型控制参照。没有必要把24篇都复现。
- 对无实机研究，更有价值的是解释方法对模型误差、接触不确定性和感知错误的行为，而不是只提高训练reward。
- 所有候选“空白”都还需要定题后的定向查新。本轮不能排除2026年其他工作或未来到2029年的研究与其重合。

## 6. 建议的下一轮精读顺序

如果选择附着不确定性控制：P02 → P03/P05 → P10 → P22/P23，并结合已读P01/P25中的模型假设。

如果选择视觉与局部导航：P12 → P13 → P07 → P16，再围绕平衡可行性与感知退化找直接竞争方法。

如果选择模型控制：P01/P25 → P18 → P15的动力学/接触部分 → P19/P20。先明确TITA的系统模型、可测状态和实际输入接口，之后才讨论残差学习或在线适应。
