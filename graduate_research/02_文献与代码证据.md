### 1.1 原始TITA RL不是只有普通PPO

| 内容 | 静态证据位置（相对上游本地根目录） | 阅读与实现边界 |
|---|---|---|
| 方法来源 | `README.md:14` 链接 [LocomotionWithNP3O](https://github.com/zeonsunlightyu/LocomotionWithNP3O) | 应追踪算法与表征的不同来源，不能只引用TITA仓库 |
| 约束RL | `configs/tita_constraint_config.py`、`algorithm/np3o.py`、`runner/on_constraint_policy_runner.py` | 已有reward、cost critic、cost advantage和违反代价更新；“加约束RL”不是空白 |
| 六项cost | 配置的`costs`与`envs/legged_robot.py:1358`起 | 位置、力矩、速度、加速度、接触力、绊碰等已纳入设计；仍需审计实际约束是否有效 |
| 本体状态与历史 | `envs/legged_robot.py:335`、`modules/actor_critic.py:764` | 已有33维本体观测和10帧历史；“加入历史”不是独立新贡献 |
| 表征学习 | `MlpBarlowTwinsActor`和`imitation_learning_loss()` | 已有Barlow Twins类辅助目标与部分特权量监督；“加自监督”需明确实质差异 |
| 非对称训练 | `evaluate()`与`evaluate_cost()` | critic使用高度、动力学特权量和历史编码；动作策略的输入更受限 |
| 随机化与执行 | 配置`domain_rand`、动作滤波/延迟、PD及轮力矩映射 | 质量/质心、摩擦、电机、PD增益和时延等并非尚待首次加入 |
| 部署 | README与 [sim2sim2real仓库](https://github.com/DDTRobot/tita_rl_sim2sim2real) | 已有Webots与板端推理路线；单纯导出部署通常属于基础工程 |

本地默认完整观测可整理为：33维本体＋187维高度＋36维特权量＋330维历史，共586维。当前Lab将36维特权量拆成6维状态与30维动力学组。**这不是部署actor必须读取586维的意思。**

`ActorCriticBarlowTwins.act_teacher()`实际只从大观测向量中切出当前本体与历史，再调用动作网络；方法名带teacher不意味着它直接读取地形真值。高度与其他特权量进入价值/代价网络。任务配置`depth.use_camera=False`。因此，该默认方案不能直接被描述成深度视觉运动控制。

另一个实验设计细节：上游任务配置默认`resume=True`，指向示例checkpoint。比较学习效率时，必须明确是否从头训练、是否使用预训练权重，以及各方法的初始化和训练预算。

以上源于本地文件读取。公开入口：[DDTRobot/tita_rl](https://github.com/DDTRobot/tita_rl)。未核对本地副本与远端当前commit的一致性，不宣称逐行审计了所有上游分支。

## 2. TITA RL背后的论文并不是唯一一篇

能确认的来源链为：

1. TITA README明确引用`LocomotionWithNP3O`。
2. 该上游仓库 [dev分支README](https://github.com/zeonsunlightyu/LocomotionWithNP3O/blob/dev/README.md) 说明作者使用HIM类似的单阶段训练思路、采用Barlow Twins，并表示当时没有发论文的时间。该说明只能代表该版本与时间，不能证明此后永远没有论文。
3. 约束算法最相关的原始研究是P02；HIM思路对应P03；Barlow Twins目标对应P04。具体实现存在修改，不能把TITA说成其中任何一篇的完整官方复现。

应分别引用“平台/实现”“约束优化方法”“表征学习方法”。本轮没有找到一篇能被确认是整个`DDTRobot/tita_rl`唯一正式配套论文的文献。

## 3. 直接相关文献：已有工作做到哪里

### P01. 用户指定的八自由度平衡—运动控制论文｜A

Wang、Ma、Chen，RICAI 2025：[A Balance-Motion Control Framework for an Eight-Degree-of-Freedom Wheeled Bipedal Robot](https://ieeexplore.ieee.org/document/11385317)。在线访问受限后，在用户Zotero找到PDF，已读六页正文并核对图表。明确采用本末科技TITA；单刚体MPC处理机身平衡，WLIP与按腿长拟合增益的离线LQR处理轮运动；包含Webots与真实TITA测试。它直接证明现成TITA可以承载控制研究，但其实验范围不能等同于任意复杂地形。详细笔记见04。

### P02. 约束RL与N-P3O｜A

Lee等，2023：[Evaluation of Constrained Reinforcement Learning Algorithms for Legged Locomotion](https://arxiv.org/html/2309.15430)。核对了CMDP、cost advantage归一化、算法比较及实机验证段落。它将物理约束与任务奖励分开，并比较多种一阶方法。

### P03. HIM内部表征｜A

Long等，2023/2024：[Hybrid Internal Model: Learning Agile Legged Locomotion with Simulated Robot Response](https://arxiv.org/html/2312.11460)。核对了部分观测、辅助表征优化、与PPO的训练关系及仿真/真实比较。

### P04. Barlow Twins｜B

Zbontar等，ICML 2021：[Barlow Twins: Self-Supervised Learning via Redundancy Reduction](https://proceedings.mlr.press/v139/zbontar21a.html)。核对原始摘要。以交叉相关矩阵接近单位阵来学习表示并减少维度冗余。它是通用表征目标；换到TITA上不自动构成新的机器人学习方法。

### P05. RMA｜B

Kumar等，RSS 2021：[RMA: Rapid Motor Adaptation for Legged Robots](https://www.roboticsproceedings.org/rss17/p011.html)。核对原始摘要与训练/部署图说明。基策略与历史适应模块组合，仿真训练后在A1上部署。

### P06. DreamWaQ｜B

Nahrendra等，2023：[DreamWaQ](https://arxiv.org/abs/2301.10602)。原始摘要报告有限传感条件下的复杂地形运动及真实室外验证。作为隐式地形/状态表征的相邻基线；本轮未审计其完整训练实现。

### P07. 鲁棒感知运动控制｜B

Miki等，2022：[Learning robust perceptive locomotion for quadrupedal robots in the wild](https://arxiv.org/abs/2201.08117)。核对原始摘要中的本体/外部感知融合与感知退化问题。

### P08. 双足/轮足盲爬楼梯｜A

Chamorro等，2024：[Reinforcement Learning for Blind Stair Climbing with Legged and Wheeled-Legged Robots](https://arxiv.org/html/2402.06143)。核对位置目标任务、非对称训练、模式观测及实验。仿真涉及不同形态，Ascento有真实台阶验证。

### P09. CTBC｜A

Li等，2025，当前页面为2026年v3：[CTBC](https://arxiv.org/html/2509.02986)。核对接触触发、前馈指导及退火、域随机化和实验设置。报告Tron1等平台的连续爬阶。

### P10. 视觉摩擦先验＋RL｜A

Peng等，2024预印本、2025修订：[Friction-Aware Safety Locomotion for Wheeled-legged Robots using Vision Language Models and Reinforcement Learning](https://arxiv.org/html/2409.09845)。核对摩擦估计、WIP实验和局限性。作者报告摩擦高估会影响成功率，估计速度也有限。

### P11. 对抗扰动与H∞｜B

Long等，2024：[Learning H-Infinity Locomotion Control](https://arxiv.org/abs/2404.14405)。核对原始摘要和公开算法/局限片段。将状态相关扰动与控制学习结合，并约束任务代价与扰动强度关系。

### P12. 运动能力感知导航｜A

Lee等，Science Robotics 2024：[Learning Robust Autonomous Navigation and Locomotion for Wheeled-Legged Robots](https://arxiv.org/html/2405.01792)。核对分层导航/运动、传统导航比较和失败案例。工作展示几何规划与真实跟踪能力、遮挡和延迟的关系。

### P13. TITA视觉语义导航：ZONDA｜A

Liang等，2026预印本：[ZONDA](https://arxiv.org/html/2607.21025)。核对多楼层规划、多视角核验、动态行人避让、消融与实机段落。**真实TITA演示是单楼层办公室，重模型在外部工作站运行，采用ROS2和MPPI执行局部运动。** 多楼层benchmark结果不能直接改写成TITA实机跨楼层能力。

### P14. 无臂轮足跌倒恢复：FTSR｜A

Hou等，2026：[Robust Fall Recovery for Armless Bipedal-Wheeled Robots via Force-Guided Learning](https://arxiv.org/html/2606.14270)。核对辅助力约束、分阶段奖励、消融与真实实验。实机为作者自研JiaRan，不是TITA。

### P15. 轮端操作物体｜A

Qin等，2026预印本：[Mobile Pedipulation for Object Sliding via Hierarchical Control on a Wheeled Bipedal Robot](https://arxiv.org/html/2606.19233)。核对TRB/TRBO模型、接触模式与摩擦约束、规划/控制及实验相关段落。采用轮腿完成物体滑动，具有真实实验。

### P16. 视觉内部模型＋规划：VIP-Loco｜A

Shirwatkar等，2026预印本：[VIP-Loco](https://arxiv.org/html/2603.14345)。核对内部模型训练、约束规划及实验。报告Go1、Cassie、轮足TronA1-W等形态的仿真结果；各形态分别训练。

### P17. 多形态扩散运动：Multi-Loco｜A

Yang等，2025预印本：[Multi-Loco](https://arxiv.org/html/2506.11470)。核对维度处理、共享扩散先验、残差策略、多critic与评价设置。涉及轮足等多种形态及真实部署。

## 4. 非RL与相邻方向文献

下列均为B级筛选，适合下一阶段按所选方向深入，尚不足以据此承诺复现成本或创新性。

| 编号与原始来源 | 核对到的问题/方法 | 阅读边界 |
|---|---|---|
| P18，Klemm等，2020：[LQR-Assisted Whole-Body Control of a Wheeled Bipedal Robot with Kinematic Loops](https://arxiv.org/abs/2005.11431) | Ascento全身控制、滚动约束、LQR平衡任务 | 模型控制有成熟参照；Ascento闭链与TITA串联腿不能直接等同 |
| P19，Chen等，2020：[Underactuated Motion Planning and Control for Jumping with Wheeled-Bipedal Robots](https://arxiv.org/abs/2012.06156) | W-SLIP简化模型、轨迹规划、LQR/WBC，摘要报告V-REP验证 | 展示纯仿真方法论文的组织方式；年份较早且不是学位标准 |
| P20，2022：[Reinforcement Learning based Hierarchical Control for Path Tracking of a Wheeled Bipedal Robot with Sim-to-Real Framework](https://ieeexplore.ieee.org/document/9708882/) | 高层RL、中层Lyapunov控制、底层PID，报告仿真与真实路径跟踪 | 模型与学习分层并非新概念，需找到具体耦合问题 |
| P21，2025：[A Control Method for Wheeled Bipedal Robots Using Improved PPO and Multidimensional Curriculum Learning](https://ieeexplore.ieee.org/abstract/document/11195032/) | PPO修改与多维课程，摘要报告并行训练与比较 | 应警惕重复“改PPO＋课程”；本轮未核对全文结论强度 |
| P22，2026预印本：[Residual Control for Fast Recovery from Dynamics Shifts](https://arxiv.org/abs/2603.07775) | 固定名义策略与有界残差应对回合内动力学突变 | 需对照突变恢复的已有机制；本轮不判定其实机证据范围 |
| P23，2026预印本：[Force-Aware Reinforcement Learning with Hybrid Sensorless Force Estimation for Wheeled-Legged Loco-Manipulation](https://arxiv.org/abs/2609.13779) | 动量观测、接触约束与时序残差估计交互力 | 物理结构化估计已有相邻工作；带臂平台不是无臂TITA的直接等价物 |
| P24，2026预印本：[Unleashing the Agility of Wheeled-Legged Robots for High-Dynamic Reflexive Obstacle Evasion](https://arxiv.org/abs/2604.23761) | 分层RL与动态闪避，报告Isaac Lab及M20实机 | 可借鉴动态避障评价；M20是不同形态，不当作八自由度双轮足复现基线 |

### P25. TITA的LQR/MPC/WBC融合控制｜A

Chen、Ma、Wang，ICEAAI 2026：[Stabilization of an 8-DoF Wheeled Bipedal Robot via Whole-Body Control with Integrated LQR and MPC](https://ieeexplore.ieee.org/document/11442373)。用户Zotero本地全文已读。LQR轮力矩参考、单刚体MPC接触力参考、加权WBC联合求解；**验证为Webots仿真，实机列为未来工作**。它提供TITA纯仿真研究实例；六页会议论文不是硕士大论文充分性的判据。
