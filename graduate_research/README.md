## 贡献与系统性

研究贡献由问题价值、主要认识或机制、相对已有工作的差异及可信证据共同论证。增加模块、改网络、移植平台和导出部署可以提供研究基础，需要进一步说明其解决的困难与可推广认识。简洁方法也可能有实质贡献，不按代码量或模块数衡量。

大论文可以围绕一个问题展开模型、方法、分析和验证；章节数量不作为统一工作量标准。当前无需先填写固定的创新点或章名。学位样本提供组织参照，不能替代本专业对具体课题的认可。
