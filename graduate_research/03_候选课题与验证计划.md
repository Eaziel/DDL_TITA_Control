# 候选课题与两种验证路线

**阅读目标：** 从中心问题出发，按理论/模型→方法→实验→结论组织候选研究；方法选择与资源验证在问题明确后决定。

证据日期：2026-10-24；2026-10-26只整理表达，未重查学校政策、在线文献或重新运行方法。

日期：2026-10-24。以下为研究建议，不是已确认的新颖性、完成承诺或同济毕业保证。文献编号见 [02_文献与代码证据.md](02_文献与代码证据.md)。

## 1. 先选问题，再选算法

三条主线都以TITA为对象，不要求改机构，也不要求最终一定采用RL。选择时看哪类失败值得解释、能否做出区别于现有工作的机制，以及能否建立有说服力的证据。

| 主线 | 核心问题 | 当前基础匹配 | 无实机时 | 有实机时 |
|---|---|---|---|---|
| A 附着不确定性下的感知与控制 | 在摩擦/接触突变与估计错误下，怎样兼顾平衡与任务性能 | 高：已有历史、约束与动力学随机化基础 | 可优先预研究，重点是可辨识性、风险与模型误差 | 适合地面切换、载荷/推扰与真实时延验证 |
| B 考虑平衡可行性的视觉局部导航 | 几何可通行的路线，为何可能超出平衡机器人实际能力 | 中：要增加真实感知链与导航任务 | 可行，须使用有TITA动力学的闭环评价 | 可使用稳定底层控制器，整机可用性要求相对低 |
| C 模型与学习融合的运动控制 | 简化模型失配时，怎样保持约束与鲁棒性 | 中：动力学建模需要额外投入 | 可行，适合力学分析与多模型验证 | 需要合适的底层接口和辨识条件 |

当前最适合先验证A的研究价值；若你的兴趣主要在视觉具身任务，B值得成为主候选。C适合希望把动力学、优化和可解释性放在中心的选择。不要同时把三条都做成大论文主线。

## 2. 主线A：附着不确定性下的感知与控制

### 2.1 一个可操作的题目雏形

**《面向附着不确定性的轮式双足机器人状态推断与风险自适应运动控制》**

初始任务限定为速度/转弯跟踪，加入未知地面切换、左右不同附着或短时接触异常。先不同时加入跳跃、语义导航与跌倒恢复。

待检验的假设：只用固定域随机化和普通历史编码，可能无法有效区分附着突变、执行器变化与正常运动误差；将可解释的动力学残差、接触模式和估计不确定性共同用于控制决策，可以改善特定工况下的失败风险与性能折中。

这是研究假设，不是已确认的已有方法缺陷。首先要证明强基线在合理工况下确实存在可重复的不足。

### 2.2 可能形成的两项关联工作

1. **物理结构化推断**：研究哪些本体观测与历史能支持对接触模式、滑移或有效附着能力的判断，并输出可靠性信息。目标不一定是回归一个精确摩擦系数；缺乏激励时，摩擦可能不可唯一辨识。
2. **风险自适应决策**：让推断及其置信度实质影响速度/加速度、动作选择或优化约束，研究错误估计下的行为与性能。可以选择约束RL、预测控制或学习增强控制，但不要把算法名称当作贡献。

“模型估计得更准”与“控制更可靠”要分开验证。即使平均估计误差下降，也可能在关键时刻高估附着，导致更差的失稳风险。

已有 [视觉摩擦先验＋RL研究](https://arxiv.org/html/2409.09845) 和 [动力学突变残差控制研究](https://arxiv.org/abs/2603.07775)，所以创新候选应进一步限定为：错误先验下的校正、可观测性与置信度、短时非平稳接触，以及它们与双轮平衡约束的关系。是否足够新颖，仍需定向查新。

### 2.3 路线1：没有整机

建议形成的完整工作包：

- 明确TITA轮地接触、驱动、传感和时延模型，说明参数从何而来。
- 建立可重复的地面切换与观测退化基准，分开训练分布与测试工况。
- 实现上述推断和决策方法，至少包含一项值得说明的新机制。
- 与原始TITA方案、一个有竞争力的历史适应方案，以及适合本问题的模型控制/约束方法比较；按最终机制选择，避免机械堆算法。
- 做结构消融、参数敏感性、未见突变与失败边界实验。
- 使用另一动力学引擎检验关键结论；若要主张板端可执行性，再加入Jetson闭环。

纯仿真下，能得出的结论是“在这些模型、误差范围和测试分布内，某机制改善了某种折中”。不能把摩擦随机化范围称为真实地面覆盖率，也不能声称实体TITA部署已验证。

### 2.4 路线2：有整机

保留同样的方法主线，增加：

- 核实关节/轮驱动命令、反馈、IMU、时间戳、控制周期和保护逻辑；区分SDK支持、可用接口与自己实际获得的权限。
- 估计名义质量、时延、驱动响应等与研究有关的参数。只辨识对当前结论重要的部分。
- 在少量有代表性的地面、载荷和指令变化下重复测试，记录失稳与人工接管，而非只保存成功视频。
- 用独立测量或经过验证的估计评估位姿/速度；如没有可靠真值，应说明测量误差。
- 检验估计错误、短时信息缺失时的控制行为，并记录实验未能覆盖的极端情况。

真实摩擦系数不必全部精确标定才能开始研究，但若论文宣称精确估计摩擦，就必须具备相应标定与误差依据。实机不是免费附加一章：调试、辨识与保护也占用研究时间。

### 2.5 最先做的预研究

在可信基线能运行以后，用4—6周回答：

1. 在合理地面切换下，原始TITA强基线是否稳定存在同类失败？
2. 失败来自估计滞后、控制决策还是接触模型错误？
3. 一个极简的结构化估计/保守决策能否改变这种失败，而非只让机器人始终走慢？

若强基线已充分解决、改进只有总体减速收益，或者结果高度依赖单一引擎的接触漏洞，应调整假设，不继续堆网络。

## 3. 主线B：考虑平衡可行性的视觉局部导航

### 3.1 题目与物理动机

**《面向轮式双足机器人的平衡可行性感知与视觉局部导航方法》**

几何上不碰撞，不代表机器人能以当前速度、姿态、附着和制动能力安全通过。可研究：如何将地形与感知不确定性转化为“当前状态下允许采取什么运动”的信息，再用于局部决策。

限定一个有深度感知的点目标导航任务，先选择坡地与狭窄通道等少量场景。低矮障碍、动态行人、楼梯、长时语义任务可逐步扩展，但不应一开始全包。

### 3.2 可能的关联研究工作

1. **平衡可行性表示**：将局部几何、机器人当前动态状态和感知置信度结合，预测某类候选运动的风险或可达性。应研究表示何时失准，避免把仿真器真值藏进部署输入。
2. **与底层能力一致的局部规划**：根据可行性选择路径、速度及必要的机身构型，使决策考虑底层跟踪误差和动态约束。与传统几何代价、固定速度和端到端策略作有针对性的比较。

可以采用学习风险模型＋MPPI/MPC，也可以采用分层策略或可解释的可达性模型。核心是可行性建模与决策耦合的实质机制，不能只把导航组件连接起来。

[P12运动能力感知导航](https://arxiv.org/html/2405.01792)、[P13 ZONDA](https://arxiv.org/html/2607.21025) 和 [P16 VIP-Loco](https://arxiv.org/html/2603.14345) 是必须区分的相邻工作。这个大方向合理，但“分层＋视觉＋运动”不能直接写成创新点。

### 3.3 路线1：没有整机

需要建立从相机观测到机器人运动的动力学闭环。若只在能瞬移/离散移动的导航环境里测试，能证明高层搜索能力，却不足以证明TITA的平衡可行性。

建议证据：相同底层控制器下比较局部决策；深度输入与特权高度输入分开；未见布局、坡度、附着和传感退化分开；统计成功率、碰撞、跌倒、制动失败、耗时与路径效率。再检验风险模型的校准与错误决策，而非只汇报任务分数。

独立引擎主要验证动力学与可行性结论；视觉渲染差异、传感噪声和地图误差还需单独设计。Jetson可验证感知与规划的联合预算，而非仅测一个小策略网络的推理时间。

### 3.4 路线2：有整机

如果厂商底层控制稳定、只开放速度接口，这条路线仍可能开展。应把贡献限定在感知和局部决策，不宣称自己完成全身底层控制。

需要实际相机/定位链、时间同步、底层命令与反馈；局部任务可以采用外部定位提供评价真值，不必同时自研SLAM。选择代表性的室内场景重复比较，记录底层追踪误差怎样导致规划失败，以及新方法怎样改变它。

与A相比，B更接近“看见环境—判断自身能力—选择行为—获得反馈”的具身任务表达；系统整合与感知分布差异也更多。对于到2029年的时间窗口，具备投入空间，但仍需要尽早收敛单一任务。

## 4. 主线C：模型与学习融合的轮腿运动控制

### 4.1 题目雏形

**《考虑接触与动力学不确定性的轮式双足机器人预测控制方法》**

先研究平面/三维模型分别丢失了什么重要动力学，再选择在线辨识、扰动观测、模型残差或自适应约束。RL可以承担残差或决策，也可以完全不用RL。

### 4.2 能形成论文的内容

- 一个为目标任务服务的模型与误差分析，明确髋侧摆、轮转、接触条件及降阶假设。
- 一项处理失配的控制机制，说明何时优于固定模型，哪些条件下仍会失败。
- 在相同状态、输入限制和计算预算下，与有竞争力的固定模型控制及学习方法比较。

需要避免：仅复现LQR/MPC，再加入通用残差网络、通过调参得到更好曲线。TITA已有P01的MPC＋离线LQR，以及P25的LQR/MPC/WBC；Ascento的 [LQR-WBC](https://arxiv.org/abs/2005.11431)、P15的 [三刚体接触模型](https://arxiv.org/html/2606.19233) 和P20分层控制，也都说明这些架构已有研究基础。

### 4.3 两种路线的区别

没有实机时，应通过明确模型假设、可分析的小系统、完整TITA动力学和独立引擎，检验控制结论对失配的依赖。若声明稳定性或安全性，证明必须覆盖声明中的系统与假设；经验无跌倒率不是稳定性定理。

有实机时，重点增加驱动/时延辨识和闭环比较。若只能调用厂商高层速度接口，就不能按“自主关节力矩控制器”的题目推进；应调整控制层级。该路线具有较强机械与控制联系，但从头建模、优化求解和底层部署的总投入可能高于A。

## 5. 暂不建议直接作为唯一主线的任务

| 任务 | 风险来源 | 更合适的位置 |
|---|---|---|
| 随机姿态跌倒恢复 | 可恢复区域、碰撞与高冲击；FTSR已有直接先例 | 有充分接触研究基础后再选，或作后续扩展 |
| 轮端推物/搬运 | 平衡与多接触、物体状态和摩擦耦合 | 高风险但有研究价值，不能作为快速补工作量 |
| 单脚旋转、极限跳跃 | 优化难、硬件风险高；只做出动作难说明普遍贡献 | 特定机制研究或示范任务 |
| 从零训练通用VLA/大模型控制 | 数据、算力、任务与验证跨度大 | 使用已有模型解决局部感知问题更实际 |
| 通用语音/YOLO/SLAM/导航拼装 | 容易成为集成演示，物理载体可替换性过强 | 研究平台或对照，另提炼明确的算法问题 |

这里没有否定这些任务的学术价值；排序依据是你目前的平台状态、学硕方法贡献目标和资源不确定性。

## 6. 无实机论文建议达到的实验强度

以下是规划建议，**不是官方最低数量要求，也不是全部必须同时执行**。

| 要回答的问题 | 推荐证据 |
|---|---|
| 方法是否有效 | 任务性能与独立物理指标，而非只看训练reward |
| 是否优于强基线 | 相同部署可观测信息、执行接口、训练预算；注明预训练与调参投入 |
| 为什么有效 | 去除关键机制、替换简单机制、理想信息上界、故意错误信息等消融 |
| 是否稳定可复现 | 先用3个独立训练种子筛选，主要结论尽量扩大至5个；预算不足时报告不确定性 |
| 是否只记住地图 | 未见布局/地形生成族；新随机种子与分布外工况分开定义 |
| 是否只适应一个引擎 | 独立引擎的接触、驱动与时间设置交叉核验；Gym与Lab均用PhysX时证据独立性有限 |
| 是否实际可执行 | 完整观测处理—估计—决策—通信链的延迟、抖动、截止期遗漏和闭环表现 |
| 结论边界在哪里 | 参数扫描、极端条件、失败分类、计算成本与性能折中 |

大量并行环境不是大量独立训练重复。置信区间需要匹配实验单位，不能把同一模型的海量回合直接当作独立训练证据。成功率、跌倒率应说明分母、终止条件与测试时长，并包含失败案例。

对于“安全”，尤其注意：限幅后力矩天然不超过限值，不足以说明策略主动尊重约束。应在与研究结论匹配的位置统计请求力矩、饱和比例、关节状态、接触风险及失稳事件。不要仅使用可能恒为零的内部cost证明安全性。

如果方法只适用于TITA，也可以研究得很深入；若声称一般性，应至少说明哪些模型特性支撑外推，或增加一个合适的第二平台。换第二个仿真机器人是泛化证据之一，不是纯仿真的普遍毕业硬指标。

## 7. 论文结构与工作量如何落地

一种可讨论的大论文结构是：

1. 绪论与文献：提出一个中心问题，并明确与最接近工作之差异。
2. 系统与问题建模：TITA动力学、传感/执行、任务和误差假设。
3. 核心研究工作一：如结构化估计或可行性表示，包含独立验证。
4. 核心研究工作二：与前者关联的控制/规划机制，分析其作用。
5. 综合验证：强基线、消融、泛化、跨引擎，以及板端或实机验证。
6. 结论与局限。

这只是组织方式。一个足够扎实的核心方法可以有不同章节结构；不能为凑章节人为拆成两个“创新”。代码迁移、环境搭建和部署应服务研究，而非成为三个互不相干的主要贡献。

## 8. 2026—2029的建议安排

| 阶段 | 主要产物与决策 |
|---|---|
| 2026年剩余时间至2027年初 | 完成可信训练基线与系统理解；取得本届培养/学位标准；明确可获得的算力和机器人接口 |
| 2027年上半年 | 选一条主线，做失败分析与4—6周预研究；形成可证伪假设、直接竞争文献表和开题范围 |
| 2027年下半年 | 完成核心方法及关键消融，形成能判断研究价值的结果；决定实机验证资源是否可靠 |
| 2028年上半年 | 系统实验与初次投稿；若走实机路线，完成有代表性的辨识和物理验证 |
| 2028年下半年 | 根据评审完善方法与证据，完成主要论文内容；保留复审、补实验与成果认定时间 |
| 2029年毕业前 | 按学院实际节点完成论文、盲审、修改及答辩；不把首次可用结果拖到这一阶段 |

这是规划，不是已确定的学校开题/送审时间。具体节点以你的培养方案与学院通知为准。

研究早期可以保留同一问题的两条验证分支，不必现在就做两套完全无关的算法。也有一些问题本身高度依赖实机，如精确驱动辨识、实体轮胎接触与热限制；这类题目若拿不到设备，就必须及时更换研究对象或结论范围。

## 9. 现在最值得完成的下一件事

**先把原始TITA方法作为可信基线建立起来，并针对一个可重复的失败工况做分析。** 这既利用现有迁移投入，又避免在尚不了解强基线能力时凭空设计新网络。

与此同时，学术范围应明确为“同济机械工程学硕的方法研究”，并核对2026级两份受限附件。对A，先看地面切换中的平衡失败；若你明显更想做视觉，改用B的“几何能通过但动力学执行失败”工况。先找证据，再决定具体算法。
