## 4. 查证方法

先看TITA子类覆盖值，再补父类默认，最后看执行分支。旧legged_robot.py中的创建、step、回调和reset分别由Lab的配置、管理器、MDP与必要环境扩展承担，无需逐文件对应。

当前USD保留9个CollisionAPI节点，其中左右leg_1/leg_2四处禁用、五处启用，与旧有效URDF的碰撞链接覆盖相同；具体几何仍不同，见19。节点数不代表PhysX cooked shape数量。高度表查询与射线求交、旧合接触力与Lab法向力也有差别，应在覆盖清单中保留。

**Q：**

> 我们做域随机化了吗？我记得还没做？不仅动作，就是所有的域随机化。

**A：** 当前RL环境已接入关节与根状态的回合重置随机化、基座质量/质心startup随机化，以及定时水平速度推扰。机器人摩擦startup也已保存；恢复系数startup也已保存；电机强度和Kp/Kd因子已保存；动作延迟已写并修正笔误，见第3节和12章。

独立的import_assets.py和非RL脚本中虽有材质随机化代码，那是另一个脚本的行为；当前RL任务的执行由env_cfg、manager和环境类决定。
