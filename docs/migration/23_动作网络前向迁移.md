## 2. 先看输入怎样变化

环境历史保存[t-10,...,t-1]，不含当前帧t。旧动作网络的forward丢掉t-10，再追加当前t，得到[t-9,...,t]，仍是十帧。随后展平成330列，经过历史编码网络得到26列。

26来自旧网络的10个辅助预测量与16个学习特征。辅助损失已按24章写入：使用中间36维状态的前10列监督前10个输出；实际训练更新尚未接通。不能把尚未训练的输出称为准确物理估计。

26列编码在前、当前33列在后，组成59列，再经过动作网络得到8个均值。此处不加tanh，不做动作缩放。训练时后续会用均值和标准差建立正态分布，采样出的动作才会交给环境ActionManager。

| 阶段 | 输入 | 输出 |
| --- | --- | --- |
| 调整十帧窗口并展平 | 历史(N,10,33)、当前(N,33) | (N,330) |
| 历史编码 | 330 | 512→256→128→26 |
| 拼接当前观测 | 26与33 | 59 |
| 动作网络 | 59 | 512→256→128→8 |

LayerNorm位置严格沿用旧工厂：第一隐层无归一化，第二、第三隐层均为Linear→ELU→LayerNorm；输出层只有Linear。不能按习惯改成每隐层都归一化，或调换ELU/LayerNorm。

## 3. 用户写入的文件

新文件完整路径：/mnt/D/BaiduSyncdisk/1ACrutial_Files/Ubuntu_2404_projects/isaaclab_ws/Tita_HWBR/Tita_Lab/src/Tita_Lab/learning/np3o/actor.py。目录及两个__init__.py按22章建立。

```python
"""History-based action network for TITA."""

from __future__ import annotations

from collections.abc import Sequence

import torch
from torch import nn


def _build_mlp(
    input_dim: int,
    output_dim: int,
    hidden_dims: Sequence[int],
    *,
    layer_norm: bool = False,
) -> nn.Sequential:
    """Build an ELU multilayer perceptron with a linear output."""
    layers: list[nn.Module] = []
    previous_dim = input_dim
    for index, hidden_dim in enumerate(hidden_dims):
        # 每层先做线性变换 Wx+b，再经过ELU非线性变换。
        layers.extend((nn.Linear(previous_dim, hidden_dim), nn.ELU()))
        # 沿用旧工厂的准确位置：第一隐层不加LayerNorm。
        if layer_norm and index > 0:
            layers.append(nn.LayerNorm(hidden_dim))
        previous_dim = hidden_dim

    # 输出层不加激活函数，动作均值不在这里裁剪。
    layers.append(nn.Linear(previous_dim, output_dim))
    return nn.Sequential(*layers)


class TitaHistoryActor(nn.Module):
    """Predict action means from current and historical observations."""

    def __init__(
        self,
        num_proprio: int = 33,
        history_length: int = 10,
        num_actions: int = 8,
    ) -> None:
        """Initialize the history encoder and action network."""
        super().__init__()
        self.num_proprio = num_proprio
        self.history_length = history_length

        # 旧网络的26个中间输出：10个辅助预测量，加16个学习得到的特征。
        # 本步只迁前向；辅助预测的监督损失后续接入。
        self.prediction_dim = 10
        self.latent_dim = 16
        encoded_dim = self.prediction_dim + self.latent_dim

        # 默认维度：330 -> 512 -> 256 -> 128 -> 26。
        self.mlp_encoder = _build_mlp(
            num_proprio * history_length,
            encoded_dim,
            (512, 256, 128),
            layer_norm=True,
        )
        # 默认维度：26+33=59 -> 512 -> 256 -> 128 -> 8。
        self.actor = _build_mlp(
            encoded_dim + num_proprio,
            num_actions,
            (512, 256, 128),
        )

    def forward(self, obs: torch.Tensor, obs_hist: torch.Tensor) -> torch.Tensor:
        """Return the action means for a batch of observations."""
        # obs为(N,33)，obs_hist为(N,10,33)，后者不含当前帧。
        # 丢掉最老一帧，补入当前帧；得到最近九帧历史加当前帧。
        history_with_current = torch.cat(
            (obs_hist[:, 1:, :], obs.unsqueeze(1)), dim=1
        )
        batch_size = obs.shape[0]
        history_flat = history_with_current.reshape(batch_size, -1)  # (N,330)。
        features = self.mlp_encoder(history_flat)  # (N,26)。

        # 顺序沿用旧网络：26维编码在前，33维当前观测在后。
        actor_input = torch.cat((features, obs), dim=-1)  # (N,59)。
        return self.actor(actor_input)  # (N,8)，动作分布的均值。
```

## 4. 谁创建与调用这个网络

这个类继承torch.nn.Module。__init__建立并保存网络层；forward定义每次输入数据时执行的计算。后续完整actor-critic对象会持有它，并在动作计算时调用它。本章可先独立用假输入核对：

```python
import torch
from Tita_Lab.learning.np3o.actor import TitaHistoryActor

actor = TitaHistoryActor()
obs = torch.randn(4, 586)
current = obs[:, :33]
history = obs[:, -330:].reshape(4, 10, 33)
mean = actor(current, history)
print(mean.shape)  # torch.Size([4, 8])
```

actor(current,history)经nn.Module.__call__执行forward，也会处理PyTorch的钩子；按官方推荐调用模块实例。[PyTorch 2.11说明](https://docs.pytorch.org/docs/2.11/generated/torch.nn.Module.html#torch.nn.Module.forward)。这里没有Lab管理器自动调用或.pyi注册，未来训练代码要明确构造并调用对象。

这段输入为随机数，输出只是未训练网络的结果，不能用它证明控制有效。网络权重属于actor对象，环境的历史缓存仍属于环境；forward只读取传入历史，不更新缓存。
