## 已解决的A2：自定义执行器需要Lab执行路径

错误为：

```text
Newton-native actuator execution does not support 'legs' (TitaPDActuatorCfg), 'wheels' (TitaPDActuatorCfg).
```

物理后端已选PhysX；独立的SimulationCfg.use_newton_actuators仍默认为True。PhysX也能经host adapter执行Newton原生模型，因此选PhysX并不会自动关闭这个开关。原生转换只识别内置模型的class_type，不能转换TitaPDActuator中的自定义compute。

用户已在VelocityEnvCfg.__post_init__末尾增加：

```python
self.sim.physics = VelocityPhysicsCfg()
# 自定义TitaPD使用Lab执行路径，PhysX物理后端保持原选择。
self.sim.use_newton_actuators = False
```

该字段属于SimulationCfg。关闭后，ActuatorCollection按class_type建立TitaPDActuator并执行其compute；物理求解仍选PhysX。此前迁入自定义模型时漏配了这个开关。

此前CPU最小复现使用原生define_actuator_properties和PhysxActuatorControl.prepare_native_actuators：True复现同一异常；False时authoring正常返回、原生组为空，候选validate通过。[CPU证据](../audits/2026-10-20_native_actuators/result.json)。用户随后已写入并完成上述真实运行。

依据：[本地官方执行器说明](/home/eaziel/IsaacLab-main/docs/source/concepts/actuators.rst)、[SimulationCfg开关](https://isaac-sim.github.io/IsaacLab/main/source/api/lab/isaaclab.sim.html#isaaclab.sim.SimulationCfg.use_newton_actuators)、[原生模型校验](/home/eaziel/IsaacLab-main/source/isaaclab/isaaclab/sim/schemas/schemas_actuators.py)。
