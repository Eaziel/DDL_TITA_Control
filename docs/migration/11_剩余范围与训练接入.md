## 2. 环境仍需核对的具体差异

- **控制与状态：** 非零动作、延迟目标、reset后的差分基准与终止步cost；现有CPU证据只覆盖给定输入。
- **时间：** 15s推扰与20s超时未被2s日志覆盖；Lab超时`>=2000`与旧Gym`>2000`差一策略步。首次reset额外step、命令/推扰相对奖励的位置仍有差异。
- **物理：** 当前聚合法向力不含切向摩擦，旧接口为合接触力；RayCaster与旧高度表在边缘可不同；碰撞覆盖已修正，具体几何仍不同。

旧仓库继续提供参数、网络计算与行为参照；用户要求需要复用算法时选独立公开实现，不直接采用旧TITA现成算法。NP3O由Python和Torch实现，自动求导和优化器使用Torch，无需自己实现底层神经网络运算。

六类cost由环境每列乘一次策略dt；k、d留给训练侧。本次已通过独立的归一化约束惩罚接入策略优化，未把六列先合并成一项负奖励；初始累计cost仍采用检查用近似。

## 4. 下一阶段的完成条件

1. **整理持续训练所需计算。** 单批六类约束已通过；后续设计可靠初始累计cost估计、非零阈值口径、辅助项与熵开关、各优化器职责，保留六类约束的区别。
2. **组织持续训练。** 将稳定计算接入algorithm／runner与自有agent cfg，跨批保留网络和Adam状态；下一批继续环境状态，按回合标志各自reset。
3. **短训练与保存回放。** 使用明确配置和预算，保存模型／优化器／配置，加载后回放并检查任务指标。
4. **完整验证。** 再逐步扩大预算与条件，评估跟踪、平衡、约束和地形，记录多seed或对照所需证据。
