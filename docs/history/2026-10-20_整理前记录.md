- 【历史验证，tita2】当时写有 `newton:selfCollisionEnabled = False`，没有显式 PhysX 对应值，能解释自碰撞关闭。后来文件已变化，不能套用到当前 tita.usd。
- 新版 PhysX 对映射属性的读取优先级为：显式 PhysX 值 > 显式 Newton 值 > 默认值；不要因为属性以 `newton:` 开头就认为 PhysX 不读取它。
- Self Collision 总开关、Collider 是否存在、Joint 直接连接对的碰撞开关、Filtered Pairs 是不同层次；需要选择合理碰撞对，不是全部开或全部关的二选一。

## 5. TITA RL 原仓库的参考事实

- README 明确基于 `zeonsunlightyu/LocomotionWithNP3O`，训练环境是 Isaac Gym；这是参考，不是已移植到本地 Isaac Lab 3.0 的项目。
- `configs/tita_constraint_config.py`：`self_collisions = 0`，注释注明 0 开启、1 禁用，这是传给 `create_actor()` 的过滤值，不能按 Python 布尔值误读。
- 原 URDF 只有 5 个碰撞形状：机身 Box、左右 `leg_3` 的 Box、左右轮子的 Cylinder。`leg_1` 无 collision，`leg_2` 的 collision 被注释。
- 原配置对 `leg_3` 接触设负奖励、对 `base` 接触设终止条件。现有奖励基于刚体合接触力，不专门区分自碰撞与撞地。
- 给所有 STL Mesh 加凸包会改变原训练用碰撞模型；刚体的质量/惯量定义与是否有 Collider 分开理解。
- Convex Decomposition 的成本取决于凸包数量、顶点、接触、过滤与并行环境数量；未做性能实测，不能声称增加固定百分比。
- Cylinder 适合平滑轮子接触，但不保证比单凸包更快；官方文档指出凸网格近似有时更快。外观精度与碰撞模型无需完全一致。
